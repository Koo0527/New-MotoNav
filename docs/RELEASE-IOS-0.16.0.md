- 圆屏隧道模式：驾车使用路线道路类型和经过校验的匹配定位，接近入口持续0.8秒或确认进入后调暗；确认在隧道外持续3秒后恢复。定位缺失或不可靠时保持原状态。亮度渐变，恢复原有昼夜/手动设置，不改写用户亮度偏好。
- 摩托车网页路线和自行车暂无可靠的隧道字段，使用导航中的“隧道”快捷按钮。此功能控制ESP32圆屏亮度，iPhone本机屏幕亮度仍由系统管理。
- 恢复12种地图风格：罪恶都市、原版、极简黑白、龙珠雷达、GTA5、赛博霓虹、复古纸地图、蓝图、掌机像素、雷达、寻宝罗盘、卫星图。原仓库0.15版将列表和保存值限制为4种，底层主题仍在。切换时取消旧地图数据，原色调色板与材质地图分开校验。

## iPhone与圆屏实测

1. 用首页搜索选一个目的地，切换三种出行方式；确认起终点、途经点保留，预览和开始导航在同一页面。自行车不支持的输入应给出提示。
2. 分别从收藏、最近目的地和高德分享进入，确认同一规划流程。摩托车分享仍使用驾车策略。
3. 模拟驾车导航，切换App导航和完整高德提示，检查导航持续、全览边距、静音/模拟速度与退出行为。
4. 连接圆屏，白天先手动点“隧道”，确认降低到夜间亮度上限；再点恢复，检查原有偏好不变。隧道中断连重连，确认同步当前有效亮度。
5. 在安全停靠或由乘客观察的条件下，验证真实隧道入口、隧道内定位丢失、出口恢复和相邻隧道；实际识别效果取决于SDK道路类型和匹配定位。
6. 逐个切换恢复的风格，检查旧地图被替换，重新打开App仍保留选择；卫星图数据较大，龙珠雷达无需底图。
7. 红绿灯读秒仍是诊断能力：在有覆盖的真实路口观察SDK是否回调/显示，不能以编译成功推断服务权限或道路覆盖。

只验证iOS；上游Android和固件更新原样合入，未编译或烧录。地图传输和12种主题的最终显示仍需对应圆屏固件实测。
