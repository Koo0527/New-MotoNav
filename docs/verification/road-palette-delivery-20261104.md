## 圆屏实际性能

使用同一明波立交样本、相同姿态和原封不动的生产双核渲染器，对普通旧材质包和新语义包交替采样。三个主题 × 昼夜 × 0/45/90 度 × 两档缩放，共 36 组；各模式预热 8 帧、测量 31 帧并取中位数。地图选择与调色板准备在计时外。

| 指标 | 结果 |
| --- | --- |
| 10% 稳定绘制预算 | 36/36 通过 |
| 每组耗时增幅的中位数 | +0.084% |
| 最差组增幅 | +0.316% |
| 两组各自跨案例中位耗时 | 旧 24,427 μs，新 24,424 μs |
| 无变化案例 | 0/36 |
| 该样本完整包 | 旧 141,843 B，新 148,124 B（+4.428%） |

该结果只衡量驻留地图的稳定绘制，不包括解压、传输、换图窗口、G 采样或手机 CPU。两组案例的跨案例中位数与逐组比值中位数是不同统计量。

临时诊断写入前重新备份现场应用并核对板卡、分区和 OTA 槽；诊断结束已恢复现场应用，随后仅在 `0x10000` 写入正式 175c.11。没有写 NVS 或分区元数据。正式版本连续运行 180 秒，未见 panic、TWDT 或内存分配失败；空闲内部可用堆约 84,328 B、PSRAM 4,265,808 B，RX 和 ACK 丢弃计数均为零。这是空闲稳定性结果，不能替代导航满负载结果。
