# 两条道路换色路径的效果试验

## 范围

本轮只进行独立离线预览与已有真机截图重放，没有修改生产 iOS／固件、写入用户缓存、安装 App 或占用圆屏串口。其他对话正在排查圆屏重启，保留其改动和设备状态。

## A：高德直接输出自定义主题

重新运行 `ios/tests/bridge-source/compare.py`，比较此前签名诊断在 iPhone 取得的上海 04-interchange 默认／初始化门控官方 Demo 样式截图。9/9 PNG 字节完全相同，RGB 改变像素为 0；状态记录中初始化、样式配置和 enabled getter 均为 true。完整 camera JSON 包含新增样式状态，不能把整体 JSON 不同视作相机不对齐；前次逐几何字段核验报告仍保留。

这说明**这个已测试 Demo 资产没有产生可见效果**，不是高德自定义样式能力不可能，也不是本次完成了一次新的明波主题真机测试。资产来自官方 11.3.100 Demo，当前内嵌地图头文件 `MAMapVersionNumber=10010600`，不能仅因二者都调用同一 API 就宣称兼容。

本次尝试浏览器入口两次均超时，用户确认控制台尚无自定义样式。缺少匹配当前 SDK 的正式导出资产，路径 A 的目标主题效果**未完成验证**；没有制造一个后处理换色图冒充 SDK 直接输出。

继续条件：在高德控制台创建一个有明显背景／道路差异的测试样式，选择匹配当前 iOS 地图 SDK 的离线文件并导出。官方文档：https://lbs.amap.com/api/ios-sdk/guide/create-map/custom 。接入时校验资产大小和 SHA，并保留默认／样式同机位 RGB 对照；先证明可见生效，再测试三主题和立交分隔。不要仅根据“开启成功”判断效果。

结果及示意：`output/map-edge-bridge/dual-path-20261104/official-replay.json`、`path-a-status.json`、`path-a-official-style.png`。这是历史真机截图的本次重放，地点是上海，不是明波。

## B：保留源图稳定道路色阶后换色

运行 `python3 ios/tests/road-multitone-preview/run.py`，读取现有明波和上海立交 1200²、2 米原始采样。现生产 Swift 重新编译并逐像素核对 QA 道路掩码，使用原建筑合成后的语义掩码保持几何一致。

只处理已有暖色道路 8／9。3×3 内部稳定颜色先分组，随后最多在原道路内传播两格；保留普通道路、原生描边保护、建筑、水域等全部其他语义。不新增桥边线，不补被遮挡道路，不给道路赋高度。

明波内部出现三组稳定暖色路面，核心亮度范围为 199.49–206.56、219.20–222.59、229.91–233.30。加上普通白色道路，预览可区分四种路面类别。现有样本不支持强拆第五组；多个 RGB 值也可能只是量化、抗锯齿变体。

输出包含三主题昼夜、同机位总览／路口放大及普通路口负例。两种 B 预览分开：

1. **仅增加色阶控制组**：保留现生产 GTA5 的 8／9 配色，仅为新增 11 指定 `#9AA4A4`。
2. **源亮度重映射**：同时按源图明暗顺序调整三个暖色类别。改善既包含额外分档，也包含整体主题明暗调整，不能混为一种影响。

明波 RLE 大小估算 148,124 → 148,762 字节（+638，约 +0.43%）；上海 208,435 → 211,337（约 +1.39%）。估算器先核对旧包实际大小一致。候选没有编码成生产可用包；目前生产拒绝索引 >10，正式接入仍需版本、能力、缓存和 App／固件回归。

Mac 上生产 Swift 分类耗时与 Python 额外处理耗时工作范围和语言不同，不比较倍数，也不据此预测 iPhone 开销。没有本轮圆屏或手机负载测量。新色阶是源图视觉差异，不能证明四种实际高度。两像素局部传播尚需地图移动、缩放和跨块一致性验证。
