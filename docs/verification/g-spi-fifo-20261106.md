# G 圆屏 SPI 刷屏崩溃与 FIFO 瞬态修复 — 2026-11-06

## 范围

本轮修复圆屏 `spi_bus_lock_bg_exit` 崩溃与 G 值 FIFO 瞬态计数中断：

- `fastPush` 从双在途中断队列改为单在途 DMA polling；每笔 `polling_end` 成功后才启动下一笔，失败记录阶段/错误码并关闭快刷/重启。
- `controlWake` 使用同一个 `flushWait` 屏刷完成屏障；删除超时后直接 `displayOn`/`setBrightness` 的分支；慢刷总等待上限 4 秒。
- `FifoStatus::Kind` 与 `FifoWait`：容量范围内、无满载/溢出的非整 XYZ 计数最多等待两次轮询或 100 ms，等待期间不读出/不积分半帧；超时、I²C 失败、溢出、满载仍使姿态失效。
- 诊断新增 `lastfifo=low:status/bytes stage=...`，在复位前保留原始计数/状态/阶段。

契约与 mission：`missions/2026-11-06-spi-flush-crash-and-fifo-transient.md`、`...-contract.md`。
